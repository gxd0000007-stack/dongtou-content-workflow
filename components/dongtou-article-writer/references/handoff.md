# 第四步交到正文

## 已有信息直接承接

读取讲法卡与参考记录，按其引用补足与本篇相关的第三步卡、第二步已选方向、第一步详细记录及依据。已有完整交接可代替文件；详细记录缺速读卡而证据足够时继续，不因格式和文件名重跑上游。

需要知道：

- 方向选择状态、主题与采用范围、当篇读者及解释起点、主要目的和阅读理由。
- 作者视角方式、我的核心观点、为什么这样看、给读者的建议、观点来源与状态；用户表达、授权代拟/试稿与已确认状态按实际区分。
- 标题、开头及其固定/候选/可调整状态，正文必须回答的问题顺序与主承诺。
- 选定 DNA、采用的语气/解释/组织规则及实际已读样本；主结构与逐段安排。
- 各段材料、依据位置、作者自述/引用/核验/未知等事实状态和条件。
- 例子与类比的用途，东头真实经历来源或省略状态、待补项、修改范围。
- 活人感写作的实际入口/版本；新长稿的具体材料清单及来路、说话位置、保护文字区间/用户依据。材料不足的真实状态和未兑现承诺。
- 输入路径、版本和输出位置。选择状态含糊时不把推荐冒称用户选定。

第四步短示范是作者判断、语气与讲法示范；可以改写衔接，不把它机械扩写成全文。第一步记录提供事实判断，速读卡用于定位；必要时回查底稿具体位置。只继承文件时不能写“本轮已重新打开原链接/看完视频”。

## 不同输入怎样处理

- **正常成稿：**方向与讲法已选定，材料能支持正文，直接写。
- **作者观点：**沿用第二至四步的五项作者视角字段。明确先聊时在对话中只问缺失观点；完整创作授权下默认直接代写，材料足够就组织有理由的本人观点，内部标“授权代拟/试稿”，不等逐项确认。没有亲历不限制观点性第一人称，缺观点字段不伪造已确认状态。
- **体裁或范围例外：**只读来源、客观报告、固定第三人称及局部修改按用户要求优先；作者视角规则不扩大允许范围。
- **用户指定试做：**按明确方向和讲法写，保留未确认状态；不要把试稿标为定稿。
- **自己的现稿：**以用户允许范围为准，完整读所给版本；只改指定段时其余逐字保留。没有全部正文就注明局部读取，不能说完成全文审查。
- **缺口影响主承诺：**先完成材料足够的部分，说明哪一段需要什么。若可用已有材料调整非固定承诺，说明修改并交对应前步；固定标题不擅改。材料确实不足时交部分稿或待补，不强凑完整教程。

- **固定文字与作者视角冲突：**指出具体标题/开头文字、冲突原因及需回交的位置，交第三步；不静默改标题、替换固定开头或假称已获同意。

## 返回与下游

原意/事实不清 → 第一步；需要变更方向/读者 → 第二步；标题开头承诺需变更 → 第三步；主文风/主结构不合 → 第四步；解释、段落和衔接 → 留在第五步修。

交第六步：正文路径/版本、标题与开头状态、主题/读者/目的、作者视角方式、我的核心观点、为什么这样看、给读者的建议、观点来源与状态、原始依据及事实状态、采用的文风/结构、作者观点及理由的正文位置、真实经历归属、正文兑现位置、待补项和修改保护范围。交第六步时传清活人感已读参考、材料来路、作者视角及修改保护范围；第六步独立执行改稿与范围检查，再交第七步最终质检。正文完成后可交第三步 B 复检标题开头，不因已有 B 功能就自动启动它或修改固定文字。

# 结构：怎么一步步展开

这些是编辑归纳的候选讲法；原稿实际顺序和可迁移部分见逐篇卡。不预设能带来爆款，不改第三步已定问题和标题承诺。

| 讲法 | 适合什么内容 | 原稿与参考卡 |
|---|---|---|
| 定义→为何重要→关键原则→操作→行动 | 概念带方法，材料足够回答“为何/如何” | [01](cards/sample-01.md)、[22](cards/sample-22.md) |
| 结果展示→读者问题→准备→操作→完成标志→边界 | 有真实过程、可跟练的教程 | [08](cards/sample-08.md)、[09](cards/sample-09.md) |
| 学习地图→理解→识别/比较→使用→自己尝试 | 零基础系统入门；只覆盖本篇有材料的范围 | [16](cards/sample-16.md)、[17](cards/sample-17.md) |
| 事件→对普通人的影响→解释机制→方法→边界 | 消息解释，有来源支持影响与机制 | [03](cards/sample-03.md) |
| 具体处境→解释为什么→分项方法→小尝试 | 共鸣与理解，可用适度自述 | [04](cards/sample-04.md)、[15](cards/sample-15.md) |
| 个人事件→判断变化→行动→可用方法 | 真实复盘，不补造结果 | [05](cards/sample-05.md)、[21](cards/sample-21.md) |
| 明确目标→几项比较条件→例子→排序/决策→局限 | 判断、选择和商业方法介绍 | [19](cards/sample-19.md)、[20](cards/sample-20.md) |

其余条目见 [58篇索引](index.json)。先检查证据适配：没有演示不选“亲测结果先行”，没有事实不写风险必然发生。广告、原作者产品引流、段落数和口播重复可不迁移。每个小节绑定当篇问题和依据，不能只交付空框架。

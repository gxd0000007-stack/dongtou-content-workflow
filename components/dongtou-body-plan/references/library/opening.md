# 标题与开头：让读者想看，并兑现

套件第三步入口已显式接入本视图：按本篇需要定位相关卡，再回读原稿；无需用户额外附路径。第四步用它检查正文承接，不重写用户固定标题。独立旧版第三步不在本次套件升级范围内。

| 抓手 | 怎么采用 | 原稿例子 |
|---|---|---|
| 先给可见成果，再接具体用途 | 本篇确有成果时说明能做什么；来源演示保留归因 | [08](cards/sample-08.md)、[09](cards/sample-09.md)、[17](cards/sample-17.md) |
| 点出熟悉处境，让读者认出自己 | 描述具体经历，不以年龄自动推断焦虑 | [04](cards/sample-04.md)、[15](cards/sample-15.md) |
| 一个清楚反差，说明为什么值得重新看 | 反差有依据；保留条件，去掉羞辱和万能结论 | [02](cards/sample-02.md)、[20](cards/sample-20.md)、[21](cards/sample-21.md) |
| 新闻/新变化带来一个读者问题 | 先讲对象及关联，不只报术语 | [03](cards/sample-03.md) |
| 交代学习范围和到达点 | “零基础/完整”须与实际步骤和先决条件对应 | [16](cards/sample-16.md)、[14](cards/sample-14.md) |
| 结果＋方法＋适用条件 | 不借原作者数字；本篇没有结果时选其他抓手 | [11](cards/sample-11.md)、[19](cards/sample-19.md) |

采用记录是“抓手→正文回答位置→依据与条件”。标题和开头分别判断；公众号同样重视最先接触的文字。悬念可选，五秒文字预检不等于真人验证；不强凑十几条标题。热度、收入、万赞和作者权威不能替代兑现。

# 四个参考视图

先看本篇需要，再查 [索引](index.json) 的摘要和 tags。每篇可以贡献多个方面，不为每个方面复制一份原文。

| 需要 | 打开 | 本步作用 |
|---|---|---|
| 怎么展开、转折、放依据与收尾 | [结构](structure.md) | 选主结构或局部组织方法 |
| 怎么吸引读者、怎样兑现 | [标题与开头](opening.md) | 第三步可直接引用；第四步核对承诺衔接 |
| 专业内容怎样讲给新手听 | [大白话解释](explanation.md) | 选具体解释动作与边界 |
| 真实经历怎样变成读者可用内容 | [经历讲法](experience.md) | 选择本篇真实经历的组织方式 |

索引记录每篇收到的原稿和参考卡；41、54是缺前文片段。先读视图挑相关条目，再读所选卡和原文锚点；使用整篇组织时读整篇。需要多少读多少，不能仅看标题便报告用了范文。实际读取范围写到本篇参考记录。

当前58篇分为原25篇小红书文稿和新增33篇Ray公众号文字，每篇按需取用。第三步直接读开头视图；第四步读所需结构、解释或经历视图；第七步从对应结构验收库读取同编号卡。来源的事实、个人经历与原稿缺口见 [来源说明](provenance.md)。发现原稿疑难文字保持原样；不能把编辑猜测变成核验事实。

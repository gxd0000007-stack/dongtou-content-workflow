# 13｜升职：角色差异与对照案例

来源：[原稿](../raw/sample-13.txt)。仅依据转写文本；“万赞”为用户报告，未验证传播效果。

## 原稿组织顺序
领导动机与交换判断 → 培养、压榨关系反复论述 → 主动付出与价值 → 提拔是找代理人 → 三种特质：翻译需求、吸收问题、归功与分享 → 省心信任总结。前半较长，不能误记为开头即三点清单。

## structure｜结构
锚点：“是老板在为自己去找一个代理人”。可迁移：先说明评价者要解决什么，再用行为比较解释标准；适用于有依据的角色分析，不照搬所有老板都如此的结论。

## opening｜标题、开头与兑现
锚点：首句“领导根本不会想要去培养除了他孩子之外的任何人”。用极强判断制造争点，正文提供作者框架与假设案例，未证明普遍真相。借明确问题与解释深度，需将判断限定到材料支持的范围。

## explanation｜大白话解释
锚点：“它像一个双向的过滤器加翻译器”。可迁移：模糊要求 → 具体协作 → 可汇报结果的对照，再用比喻概括；适用于讲清角色工作。10 毫秒、10%、五个点是案例数字，不是实测。

## experience｜经历讲法
无可确认的作者亲历叙事；“我举个例子”后的团队、故障和庆功会主要是假设，不能移植为东头带团队的经验。

## 采用边界
领导动机、升职规则与交换观为作者主张。转写错词较多；原稿粗口、羞辱与绝对化不默认采用。提炼职责对照，不把压榨合理化或据此给普遍职场保证。

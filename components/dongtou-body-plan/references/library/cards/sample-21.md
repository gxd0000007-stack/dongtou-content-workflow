# 21｜从自己的误判，转向理解新手

原题：厌蠢会真的会让你少赚很多钱……
来源：[完整原稿](../raw/sample-21.txt)。稿内署名西西；用户报告万赞，未核验效果。

## 原稿组织顺序

判断及收入自述 → 新手提问、作者拒绝 → 同行结果对照 → 复盘职场与客户环境变化 → 医生、律师及认知盲区类比 → 尊重新手专业背景 → 收集问题、方案与课程 → 结果自述 → 下一次如何反应、账号定位。

## 四类可复用参考

- **structure 结构**：锚点：“后来我就复盘”。行为造成困扰 → 解释旧习惯 → 换理解方式 → 具体调整及结果。适合复盘，不需每篇都有收入展示。
- **opening 标题与开头**：锚点：“厌蠢会让你少赚很多钱”。把态度与自身损失联系，正文讲作者改变；仅单人自述，不能写成普遍利润定律。
- **explanation 大白话解释**：锚点：“他连点哪个按钮都不知道”。用新手问句和最小操作说明认知起点，再以跨领域例子换位理解。适合拆AI门槛；不沿用贬低读者的称呼。
- **experience 经历讲法**：锚点：“把之前那些曾经气到我的蠢问题全部收集起来”。坦诚自己原来的不足，写出改变后的实际动作。需东头真实问答及变化，不凭空给东头贴不耐烦的人设。

## 采用边界

粉丝、同行收入、销量、零差评和排行全是源稿陈述，未独立核验，不能移植。提问者画像部分为作者设想，不能当用户调查。“艺人公司”等转写存疑。服务方法不等于保证盈利。

# 04｜二十几岁焦虑：共鸣、经历、建议

来源：[原稿](../raw/sample-04.txt)。仅依据转写文本；“万赞”为用户报告，未验证传播效果。

## 原稿组织顺序
命名年龄阶段 → 同龄人分层与选择困境 → 可跳转的观看说明 → 三种焦虑 → 作者毕业、上班、辞职经历 → 四项建议 → 小练习 → 未来话题与留言。

## structure｜结构
锚点：中段“我觉得自己最主要焦虑的原因总结起来有三点”。可迁移：先把模糊感受分成问题，再逐项解释，最后给可尝试的建议；适用于共鸣与讨论型内容。原稿四项建议不是前三个问题的一一对应答案。

## opening｜标题、开头与兑现
锚点：开头“这个班儿是越上越上不下去，但辞职却又不知道该干什么”。可借用能被读者认出的两难处境。正文用个人视角承接，不把个人建议写成所有人都能“安稳度过”的保证。

## explanation｜大白话解释
锚点：后段“目标驱动是我要跑完一场马拉松”。可迁移：用同一件事的两种说法解释抽象区别，再请读者检验是否理解；适用于概念对照。船与原型比喻仅帮助理解，不证明心理机制。

## experience｜经历讲法
锚点：“当我开始觉得这个班没意思之后，我去辞职做自媒体”。可迁移：选择节点 → 失去原有安排 → 新问题 → 自己尝试的办法；条件是有东头的真实经历，只解释能从该经历支持的判断。

## 采用边界
作者求学、咨询、爱好与辞职经历不可移植。社会学与心理判断未核验；“剁在自己手里”等存在转写疑点，不能据此补原句或作者身份。

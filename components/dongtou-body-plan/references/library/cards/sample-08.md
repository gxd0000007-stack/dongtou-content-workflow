# 08｜App 装到手机：展示结果与分层教程

来源：[原稿](../raw/sample-08.txt)。仅依据转写文本；“万赞”为用户报告，未验证传播效果。

## 原稿组织顺序
已装好结果 → 评论区需求 → 本篇范围与前篇入口 → 保存项目 → 部署网页、检查电脑与手机 → 解释 PWA → 改造与再部署 → 与上架原生 App 的边界。

## structure｜结构
锚点：“但它毕竟是网页嘛”。可迁移：先完成可用的第一层，再按读者需要解释下一层及差异；适用于有分层交付的教程，不必须一次讲完全部技术。

## opening｜标题、开头与兑现
锚点：开头“你看现在点开就可以直接用了”。以可见结果和真实提问引入教程，后文给步骤与检查。采用条件：本篇确有演示与完整步骤；只有转写稿时不能声称已看到手机效果。

## explanation｜大白话解释
锚点：“看起来像APP”与“骨子里呢就还是网站”。可迁移：熟悉外观＋关键区别＋使用收益，解释新概念；需说明差异，不能断言与原生 App 完全一样。

## experience｜经历讲法
锚点：“我没有用到API I的key”。可迁移：用自己的演示项目说明一项设置为什么可省略；必须交代项目条件，不把演示当通用配置。

## 采用边界
“补充这一行代码”“输入这一段命令行”所指内容未给出，缺截图和参考链接；转写工具名有疑点。部署可用性、收费和软件步骤未核验，不从此卡生成可执行命令。

# 29｜从识别高手到拆出方法

原题：一定要学会辨别身边成长极快的人

来源：Ray 公众号文字；用户原编号 04。[收到的原稿](../raw/sample-29.txt)。

使用范围：按本篇需要选功能；原作者观点和经历仍归原作者。

## 原稿组织顺序

- 识别他人关联自身成长
- 成长复盘与提问引出答案
- 标签化归因改成过程问题
- 偏差解释补充为什么误看
- 界定借鉴对象是体系
- 获取方法与识别问题
- 持续结果与可教体系两条标准
- 个人应用过程而非只炫结果
- 一项拆解作业收束

## 四类可复用参考

### 结构

原文锚点：但现在有一个很大的问题：社交平台把每个人都包装成了“好像很厉害”的样子

观察：讲学习方案后主动提出识别风险，使标准有来由。

可迁移：推荐AI教程或Skill前先说明容易误判哪里，再给筛选维度。

边界：不能为了推自己的产品夸大别人不可靠。

### 标题与开头

原文锚点：昨天晚上上课，恰好有人问我

观察：用真实提问让读者进入作者的思考现场。

可迁移：采用用户实际问过的问题作为文章起点。

边界：不可虚构课堂、学生或结果。

### 大白话解释

原文锚点：什么叫体系化方法，就是从 0 到 1 搞明白

观察：用资源、顺序、节奏和关键点展开抽象体系。

可迁移：解释Skill或工作流时逐项说明输入、动作、检查和完成条件。

边界：体系化不是把步骤名堆成大词。

### 经历讲法

原文锚点：一路抄，一路调，一路练

观察：用持续调整呈现学习过程，弱化天赋神话。

可迁移：讲东头真实参考、调整、测试某一写作方法的过程。

边界：抄的对象应为方法而非受保护原文和别人经历。

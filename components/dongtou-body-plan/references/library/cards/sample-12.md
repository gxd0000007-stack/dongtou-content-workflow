# 12｜被针对：场景递进与行动转折

来源：[原稿](../raw/sample-12.txt)。仅依据转写文本；“万赞”为用户报告，未验证传播效果。

## 原稿组织顺序
重复标题判断 → 玩笑、冷落等轻微事件 → 甩锅等升级 → 旁观者成本解释 → 沉默与等待的困境 → 停止默认配合 → 具体动作 → 从被理解转到改变局面 → 课程入口。

## structure｜结构
锚点：“慢慢的，你就会发现，针对开始升级”。可迁移：用可识别的小事件递进，让读者理解问题如何变化，再提出能做的动作；适用于有材料的情境分析。课程导流为商业部分，不默认作为结尾。

## opening｜标题、开头与兑现
锚点：首句“大家都知道你是被针对的，但是他不会帮你”。标题与首句一致，后文解释作者为何这样判断，再给行动方向。采用条件：限定具体局面，不把对他人内心的猜测写成所有人的事实。

## explanation｜大白话解释
锚点：“下一次不要着急接话，不要着急补位”。可迁移：把“边界”这种抽象概念翻成一个看得见的行为，再说明希望改变的互动；不能保证一个动作就能解决职场针对。

## experience｜经历讲法
无可确认的作者亲历。玩笑、甩锅与旁观者叙述都是泛化情境，不可变成东头自己被针对或处理成功的故事。

## 采用边界
“理性选择”“零成本就可以用”等是作者解释，未提供访谈或证据；有“揭锅”等转写疑点。借用场景与行动衔接，避免猜动机、受害者归责及复制课程承诺。

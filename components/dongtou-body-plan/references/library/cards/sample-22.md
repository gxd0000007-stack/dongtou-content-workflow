## 原稿组织顺序

掌控人生的主张及股权选择 → 创业结果自述 → 五步预告 → 兴趣、能力、付费需求 → 研报与最小产品验证 → 商业计划六项和用途 → 注册公司 → 销售交付、流程、团队循环 → 重申商业系统与账号定位。

## 四类可复用参考

- **structure 结构**：锚点：“5个具体的行动步骤”。先说明各步目的，再给检查问题和HR例子，沿准备到执行顺序推进。适合行动指南；步骤须适配本篇真实前提。
- **opening 标题与开头**：锚点：“看完这条视频你就知道如何开干了”。以读者愿望和行动收获入题，正文提供方向清单；不等于完整操作手册或成果保证。
- **explanation 大白话解释**：锚点：“把我觉得转变成市场证明”。用前后状态解释调研用途，并以具体服务举例。适合把专业名词翻成能完成的任务，验证标准仍需明确。
- **experience 经历讲法**：无完整亲历变化链。创业年龄和利润主要作资历，HR是示例，不能推定是作者实际业务或移植成东头经历。

## 采用边界

股权可行性、公司注册保护与费用、乔布斯归属等未核验，不能作为法律、财务依据。MVP、BP等可提炼解释方法，不直接使用商业判断。与23、25重复的半年百万自述不当三份独立证据；转写缺句保留存疑。

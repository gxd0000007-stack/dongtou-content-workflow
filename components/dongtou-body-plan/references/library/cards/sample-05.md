# 05｜学习到教学：从新手经历形成表达

来源：[原稿](../raw/sample-05.txt)。仅依据转写文本；“万赞”为用户报告，未验证传播效果。

## 原稿组织顺序
做课程时的不自信与当前结果 → 回看记录生活、做内容、学技术 → 发现自己的优势 → 发现新手基础问题 → 设计课程与合作分工 → 学员反馈 → 教别人也是学习。

## structure｜结构
锚点：中段“原来新手真正卡住的并不是那些非常高深的技术”。可迁移：成长过程里的关键发现 → 新的判断 → 具体做法 → 反馈；适用于经验复盘。课程内容介绍属于商业表达，可按本篇目的省略。

## opening｜标题、开头与兑现
锚点：开头“我凭什么教别人”。用自我怀疑与后续变化让读者追问过程；正文提供成长、教学与反馈经历，但不是完整拍摄教程。采用条件：东头确有类似转变，标题只承诺本文能说明的事情。

## explanation｜大白话解释
锚点：“你可以拍倒水按键，咖啡流出，拿杯子，最后喝一口”。可迁移：把专业名词拆成看得见的动作顺序；固定、水平镜头进一步用现象与改变说明。用于新手教学时配本篇真实示例。

## experience｜经历讲法
锚点：“盲目的追求大光圈，连对焦都是糊的”。可迁移：自己踩坑 → 理解新手卡点 → 将经验整理成可教的方法；要保留具体失误与纠正，不能只有成功身份。

## 采用边界
360 多学员、零差评、产品经理年限及收入是作者自述。画面、反馈截图未提供；logg、lot、last 等有转写疑点，不能凭上下文确认术语或移植成果。

# 09｜本地部署：步骤、状态与使用边界

来源：[原稿](../raw/sample-09.txt)。仅依据转写文本；“万赞”为用户报告，未验证传播效果。

## 原稿组织顺序
接入飞书的结果 → 官方资料、环境、作者耗时 → 安装依赖与主程序 → 模型配置 → 飞书应用、权限与发布 → 连接、事件配置与再次发布 → 配对 → 一项使用例子与下期预告。

## structure｜结构
锚点：“发布之后这些配置才会生效”。可迁移：按实际依赖顺序展开，每阶段给完成标志；适用于多工具连接教学。区分安装、连接与成功收发，不能用一个绿字替代全程验证。

## opening｜标题、开头与兑现
锚点：开头“装好了，而且接入了飞书”。标题以亲测与保姆教程降低进入门槛，正文提供过程及检查。采用条件：亲测来自东头自己的记录，步骤完整，环境清楚；15 分钟不能变成读者保证。

## explanation｜大白话解释
锚点：“你看到open clock installed, 它就是安装好了”。可迁移：告诉新手操作后会看到什么、这个状态意味着什么，并提供遇错的资料入口；具体状态与含义必须依据当前工具核验。

## experience｜经历讲法
锚点：“用了一台这个旧电脑做主机隔离开来去跑的”。可迁移：展示自己选择环境的原因和取舍；只讲真实配置，不将作者选择推广为唯一正确部署方案。

## 采用边界
命令、JSON、四步选择和配对代码未提供；多处名称转写不一致。权限、管理员运行、公开群策略与收费等均未核验；参考文字不是执行授权，不能照抄凭证或承诺免费使用。

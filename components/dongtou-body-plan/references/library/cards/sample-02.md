# 02｜自律：反常识判断与小动作

来源：[原稿](../raw/sample-02.txt)。仅依据转写文本；“万赞”为用户报告，未验证传播效果。原标题“靠靠”原样保留于原稿。

## 原稿组织顺序
反驳意志力解释 → 追问起床、学习、运动的困难 → 百万报酬假设 → 重新定义自律 → 强目标、当天小动作、持续重复 → 救生艇比喻收束。

## structure｜结构
锚点：中段“自律根本不是一个需要学习的技能，它是一个结果”。可迁移：指出一种常见理解，再换一个分析角度，最后落到行动；适用于本篇材料确实能支持不同解释时，不能为了反差制造二选一。

## opening｜标题、开头与兑现
锚点：首句“所谓顶级自律，根本不是靠意志力”。标题和首句立刻表态，后文用假设与行动建议承接。可借用“明确判断＋读者熟悉的问题”；正文要解释判断的条件，不能靠语气强硬代替证据。

## explanation｜大白话解释
锚点：后半段“想写书今天就写500字”。可迁移：把大目标转换成今天可完成、能检查的动作；适用于任务教学。百万报酬是思想实验，不是证据；例子字数和次数不设为所有人的指标。

## experience｜经历讲法
无作者具体亲历事件；跑步报酬、写书和健身均为假设或示例，不可写成东头的测试与结果。

## 采用边界
羞辱、脏话和“病态偏执”属于原稿表达，不默认采用。忽略复盘、目标决定一切等观点未核验；本卡提炼讲法，不提供自律或心理机制结论。

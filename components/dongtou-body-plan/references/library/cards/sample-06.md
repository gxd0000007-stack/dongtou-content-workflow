# 06｜专注习惯：个人做法与广告嵌入

来源：[原稿](../raw/sample-06.txt)。仅依据转写文本；“万赞”为用户报告，未验证传播效果。

## 原稿组织顺序
朋友对作者效率的好奇 → 作者归因为专注 → 计划习惯 → 远离干扰与启动仪式 → 较长咖啡机介绍 → 下一步行动 → 扩展到效率与成长的结尾。

## structure｜结构
锚点：“为什么有的时候制定的目标和计划没有用，是因为没有定好下一步行动”。可迁移：一项习惯用“原来的困难、改变的动作、预期用途”展开；适用于习惯复盘。咖啡机广告是原稿真实组成部分，抽取教学结构时单独标出，不当核心论据。

## opening｜标题、开头与兑现
锚点：开头“这个高专注力是从我改变了三个不好的习惯开始的”。标题给读者明确数量与可改变的方向，正文对应计划、干扰、行动。采用条件：本篇确有可解释的三项，不因原稿数字而强凑三点。

## explanation｜大白话解释
锚点：“列出计划就像是一个清扫的工作”。可迁移：类比后立即给前一天列计划、标优先级等具体动作；适合把抽象方法落到日常。类比不是大脑机制的证明。

## experience｜经历讲法
锚点：“我喜欢在前一天就把第二天的计划全部列好”。可迁移：以实际日常做法解释方法，交代适用时段与卡点；仅采用东头真实做过的行为。

## 采用边界
咖啡机功能、性能与感受属于广告或作者自述；“每周只工作4小时”等效果未验证。原子习惯引述与“困眠”等转写内容有疑点，不默认采信。

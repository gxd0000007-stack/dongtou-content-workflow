# 大白话解释：让小白听懂

先明确读者不懂哪个概念，再选一种能解决该疑问的解释动作。白话不等于删除关键条件，类比有用不等于类比就是事实。

| 动作 | 在本篇如何落地 | 参考 |
|---|---|---|
| 一句普通话定义→熟悉用途→边界 | 先说是什么、能做什么；保留与真实对象的差别 | [08](cards/sample-08.md) 的PWA说法 |
| 用熟悉物件建立关系 | 说明类比各部分代表什么，哪里不对应；核验真实机制 | [14](cards/sample-14.md) 的预算/照片类比；[03](cards/sample-03.md) 的考试类比 |
| 并排比较易混概念 | 每项回答“适合谁、做什么、有什么不同”，避免术语堆叠 | [16](cards/sample-16.md)、[07](cards/sample-07.md) |
| 同一具体场景，比较两种想法/动作 | 用可理解情境解释抽象判断；假设例子标注假设 | [20](cards/sample-20.md) 的柠檬例子；[13](cards/sample-13.md) 的指令翻译 |
| 动作→为何做→完成标志→出错怎么办 | 教程须有实际步骤和依据，缺代码/截图明确留缺口 | [08](cards/sample-08.md)、[09](cards/sample-09.md) |
| 用几个具体例子辨认抽象区别 | 保留类别定义和适用范围，不把个人偏好变真理 | [04](cards/sample-04.md)、[15](cards/sample-15.md) |

记录“本篇难词/难点→白话解释→例子→重要条件→来源”。陌生概念首次出现解释具体作用；已清楚的词无需再比喻。07/14医学机制、16许可证等原稿说法未经本次核验，不能直接作为解释事实；只借组织动作。

# 58 篇结构参考库的来源与边界

本库来自用户提供的 25 篇逐字稿，以及已经整理的《25篇结构验收库-v0.1》。原文保存在 `raw/`，25 个文件按字节完整复制，没有改写、纠错或裁剪。完整结构卡从原库 `data/library.json` 提取，共 25 篇、321 个阶段；原库版本为 `0.1.0`，该汇总文件的 SHA-256 为 `a71fc89743fb1ecd18ec2dc999f6610cdc2e558b5ba9e700fc98ef7e3fe43fe5`。

每篇有三种入口：[索引](index.json)列出标题、短名称、家族、阶段数和原稿 SHA-256；`cards/sample-NN.md` 供阅读；`data/sample-NN.json` 保留完整卡片字段，包括原稿路径、原稿哈希和各阶段 `source_span`。JSON 不重复保存 `source_text`，完整正文只存于对应 `raw/sample-NN.txt`。JSON 内的 `source_path` 相对于本目录 `references/library/`；Markdown 原稿链接相对于卡片所在目录。所有运行所需资料随 Skill 保存，不依赖原库仍在本机。

原稿中的事实、数字、人物案例、效果承诺和“万赞”传播表现未在本次独立验证。保存原稿和核对哈希只能证明材料完整，不表示内容真实、已经达到传播效果，也不表示它们是东头本人的经历。引用或迁移其中事实仍需本篇可靠材料；原作者观点、案例与用户亲历应分开归属。

本库只提供结构功能参考：看各环节承担什么任务、如何衔接、需要哪些材料、什么情况算通过或不通过。原稿顺序属于观察；“核心／可调”、适用条件和迁移写法属于分析建议。只有被选中并写入本篇结构约定的功能才作为该篇结构验收依据，不能要求每篇凑齐整个库的全部阶段，也不能照搬原稿措辞、夸大承诺或事实结论。本库不代替文风 DNA、当篇选题判断或事实核查。

`source_span` 使用完整原稿从 0 起算的字符位置，右端不包含；原25篇从 `body_start_character` 到原稿末尾连续覆盖正文；新增33篇从 `body_start_character` 到 `body_end_character` 连续覆盖实际分析范围。41的界面尾部由 `excluded_source_spans` 标明，未用于讲法分析。每段哈希取对应原文片段 UTF-8 字节。制作目录中的 `packaging-verification.json` 保存本次复制与链接核验结果，它是交付证据，不属于 Skill 运行文件。

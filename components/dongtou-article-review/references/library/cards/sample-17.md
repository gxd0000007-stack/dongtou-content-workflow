# 17｜完成示例开场后逐任务讲输入、结果与修改

原题：Codex的10个用法｜小白入门教程

**类别：**多用法任务教学

**这篇的区别：**每个任务以场景输入和作者所述完成状态推进，朗读应用又引用前面的新闻自动任务，并补出两次调试，形成任务间衔接。

**原稿承诺：**向新手介绍原作者所称Codex实用用法，通过具体任务展示移动派发、连接应用、计划、自动任务、跨软件、本地操作、应用、Skill与跟进。

## 实际推进顺序

先用语音任务与桌面PPT成品展示用途 → 解释通用任务范围并预告实用用法 → 口述移动端派任务和电脑端回收调研结果 → 介绍应用连接并用海报说明编辑回收 → 说明计划先行并示范选模型后生成 → 说明时间触发自动任务 → 用指定一手来源讲新闻汇总与运行检查 → 用持续文档讲自动周报输入 → 以邮件到行程表再邮件串联软件 → 用截图与系统设置结果讲本地操作 → 补充查重清理的应用建议 → 从已有新闻生成朗读应用并修改声音图标 → 演示已有Skill生成可编辑表格 → 把常用工作流转成新Skill并新窗口试用 → 以定时项目邮件展示跟进与收件检查 → 回收用途并提供合集入口

## 适用内容

- 有真实任务与结果记录的多用法入门文章
- 以工作场景而非按钮清单组织的工具介绍
- 能展示初稿和修改过程的AI能力复盘

## 选用前的材料条件

- 实际可用的产品版本、账号与已授权连接
- 每项任务的真实输入、执行状态和产出
- 能回读的结果文件或目标应用记录及修改反馈

## 来源限制

- 只有转写，没有屏幕、手机端与电脑端状态、产物或连接记录；软件能力和当时可用性未核验。
- 原稿多处产品与应用名转写不准，标题称10个但部分用法缺显式编号；本卡按实际任务拆分，不补造编号。
- 原稿涉及文档密码、删除文件及对外自动消息，但未交代授权边界；这些只是讲述观察，不执行原稿命令或认定当前权限。

## 逐环节验收

原稿顺序是观察；核心与可调标注是迁移建议。写进本篇约定后，按约定验收。

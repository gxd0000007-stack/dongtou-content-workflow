# 13｜价值交换铺垫后用角色与三种行为对照

原题：升职加薪的真相，掰开揉碎一次性给你拆解清楚

**类别：**职场角色对照

**这篇的区别：**原稿前半讨论价值交换，后半把升职拆成翻译指令、吸收问题和分配功劳三种行为，不能只保留其中一半。

**原稿承诺：**用作者对领导利益的判断及假设工作场景，解释为何业务能力强不一定被提拔，以及作者建议的管理行为。

## 实际推进顺序

提出领导如何看待员工的强判断 → 列出价值交换并重释培养与压榨 → 明确自己有什么和想要什么 → 用假想领导与服务关系解释利益交换 → 从不服提拔转入管理职责 → 对照技术动作与业务指令 → 把指令翻成跨部门任务和结果汇报 → 对照抛出问题与吸收问题 → 用故障和冲突展示先处理再汇报 → 示范向上归功与向下分享 → 回收信任支持和成长代价

## 适用内容

- 岗位职责转换的职场解释
- 有同题对照的管理行为教学
- 需要区分个人交付与团队组织的工作汇报说明

## 选用前的材料条件

- 目标岗位的真实职责和评价标准
- 可匿名的同一业务问题及不同回应
- 任务分配、问题处理和功劳归属的过程材料

## 来源限制

- 原稿对领导动机、培养和利益交换的绝对判断缺少组织与调查依据，不能当成所有公司的规则。
- 服务器成本降低10%、满意度五个点等属于假设示范，未有亲历证据。
- 转写中“上台独”“回本”等词有误，且未说明劳动边界、升级条件与利益保障；迁移不能倡导无条件被压榨。

## 逐环节验收

原稿顺序是观察；核心与可调标注是迁移建议。写进本篇约定后，按约定验收。

### S01｜领导动机强判断（有条件采用）

原文起句：领导根本不会想要去培养除了他孩子之外的任何人，

原稿位置：完整原稿字符 36–178（从0计数，右端不含）；连续覆盖正文 0.0%–3.3%。

**这一环的作用：**以领导关注自身位置、员工被当工具的判断冲击读者对培养的期待。

**如何衔接：**设置价值交换框架，随后列出什么能力被需要。

**讲述方法：**绝对判断和员工工具比喻。

**保留／替换条件：**只有可靠组织观察时采用具体判断；迁移应改成某些评价或使用关系的可见现象。

**本篇需要的材料：**

- 可公开的评价、任务或资源分配记录

**怎样算通过：**

- 说明判断适用的组织和观察范围。

**这些情况不通过：**

- 把所有领导的内心当作事实。

**迁移到东头：**从真实岗位评价或任务分配现象提出问题。

### S02｜可交换价值与机会（有条件采用）

原文起句：如果说你可以给你的领导提供他想要的价值，

原稿位置：完整原稿字符 178–414（从0计数，右端不含）；连续覆盖正文 3.3%–8.8%。

**这一环的作用：**列出办事、资源、业务、时间和情绪等作者认为可交换的价值，连接被使用与获得机会。

**如何衔接：**将开头框架具体化，接下来重释培养和压榨的关系。

**讲述方法：**不同价值类型枚举与机会链条。

**保留／替换条件：**讨论价值交换时应明确合法职责和本人选择，不能把加班随叫随到列为必需。

**本篇需要的材料：**

- 岗位需要的实际价值
- 本人能提供的能力及边界
- 承诺回报和兑现情况

**怎样算通过：**

- 价值与具体需求对应，投入与收益不写成必然关系。

**这些情况不通过：**

- 只列讨好行为，未说明工作价值和本人边界。

**迁移到东头：**写明业务需要、本人能力和愿意承担的职责。

### S03｜重释培养与压榨及层级（核心）

原文起句：在这儿我想跟大家去说一个观点啊，叫做培养和压榨是不矛盾的，

原稿位置：完整原稿字符 414–761（从0计数，右端不含）；连续覆盖正文 8.8%–16.9%。

**这一环的作用：**提出使用过程也可能获得能力的解释，并以领导同受上级压力说明层级关系。

**如何衔接：**从被需要的类型转到怎样理解投入的得失，再引出个人目标。

**讲述方法：**重定义加上下级处境类比和总结。

**保留／替换条件：**选用本结构时保留对关键概念与利益关系的澄清；原稿绝对论应转为有条件观察。

**本篇需要的材料：**

- 实际任务带来的能力收获
- 任务负担和兑现的利益
- 上级目标的可查材料

**怎样算通过：**

- 区分能力成长、被使用和实际利益，不互相替代。

**这些情况不通过：**

- 只把压榨重新命名为培养，未交代损失与回报。

**迁移到东头：**区分AI或职场任务中练习价值、劳动成本和正式回报。

### S04｜自有资源与目标（核心）

原文起句：总结下来就是，如果你对于他来讲是没有价值的，

原稿位置：完整原稿字符 761–868（从0计数，右端不含）；连续覆盖正文 16.9%–19.4%。

**这一环的作用：**收束前面的交换判断，提出先知道自己有什么和要什么，再决定主动投入。

**如何衔接：**把外部规则解释转向本人选择，随后用能力清单具体化。

**讲述方法：**总结后给两个自查问题。

**保留／替换条件：**选用本结构时保留资源与目标的对应检查，不沿用无付出必无回报的绝对式。

**本篇需要的材料：**

- 本人现有能力或资源清单
- 希望获得的职位、经验或回报
- 可接受投入上限

**怎样算通过：**

- 有具体资源、目标及投入条件。

**这些情况不通过：**

- 仅说主动付出，未回答本人要得到什么。

**迁移到东头：**在接AI项目或职场任务前明确能贡献什么和希望获得什么。

### S05｜能力清单与不同选择（核心）

原文起句：我举个例子啊，比如说你有背景资源，你有沟通协调的能力，

原稿位置：完整原稿字符 868–1088（从0计数，右端不含）；连续覆盖正文 19.4%–24.6%。

**这一环的作用：**举出资源、沟通、专业等不同价值，并承认只想自在的人可能选择不展示某些能力。

**如何衔接：**具体化自查，下一段转到假想领导视角。

**讲述方法：**能力枚举加两种目标分支。

**保留／替换条件：**选用本结构时保留不同目标对应不同投入，不把外貌或无条件待命当统一标准。

**本篇需要的材料：**

- 与目标岗位相关的真实能力证明
- 本人希望争取或暂不争取的机会

**怎样算通过：**

- 至少展示一种能力如何对应需求；不同目标允许不同选择。

**这些情况不通过：**

- 能力列表很多，未说明各自服务哪个目标。

**迁移到东头：**按真实任务需求展示能力，允许选择稳定交付或承担管理职责。

### S06｜假想领导的激励视角（有条件采用）

原文起句：那站在领导的角度，他的心里就是工作是你自己考上的，

原稿位置：完整原稿字符 1088–1334（从0计数，右端不含）；连续覆盖正文 24.6%–30.3%。

**这一环的作用：**用假想领导独白表达基本工资与额外机会分配的不同逻辑。

**如何衔接：**承接个人选择，给后面的服务角色类比铺垫。

**讲述方法：**换位独白和蛋糕比喻。

**保留／替换条件：**有助解释规则时采用，但必须标为假想视角而非对方原话。

**本篇需要的材料：**

- 岗位薪酬与奖励分配制度
- 可公开的机会分配依据

**怎样算通过：**

- 假想独白有标签，制度事实另给依据。

**这些情况不通过：**

- 把猜测写成“最真实的想法”，没有来源。

**迁移到东头：**用公开的岗位激励规则解释基础职责和额外机会。

### S07｜服务关系类比与利益成本（有条件采用）

原文起句：我们换位思考一下啊，比如说你每天压力很山大，

原稿位置：完整原稿字符 1334–1738（从0计数，右端不含）；连续覆盖正文 30.3%–39.8%。

**这一环的作用：**用清洁工、司机服务关系类比领导只希望任务稳定，再说明作者认为领导倾向较小成本换取较大价值。

**如何衔接：**解释前段激励观点，随后转回看清规则的评价。

**讲述方法：**熟悉关系类比后重申成本与交换。

**保留／替换条件：**只有角色关系确实可比时采用，注明类比局限，不能用类比证明所有动机。

**本篇需要的材料：**

- 可比较的任务与责任关系
- 实际资源投入和利益兑现记录

**怎样算通过：**

- 说明类比对应哪项职责，未将角色地位直接等同。

**这些情况不通过：**

- 类比只有贬低员工，未解释评价关系。

**迁移到东头：**用委托任务的可靠交付解释省心，并明确资源与职责界限。

### S08｜现实限定与提拔困惑（核心）

原文起句：我跟他讲啊，我们又觉得说压榨这个东西，它是一个好的东西没有，

原稿位置：完整原稿字符 1738–1976（从0计数，右端不含）；连续覆盖正文 39.8%–45.3%。

**这一环的作用：**一方面说明作者未把压榨视为好事，另一方面以苦干者未获提拔的困惑引出下一组规则。

**如何衔接：**回收前半价值交换，转换到升职的职责问题。

**讲述方法：**立场限定后用不服气场景设问。

**保留／替换条件：**选用本结构时保留从交换框架到岗位评价的转场，删去羞辱读者的话。

**本篇需要的材料：**

- 业务能力强却未任管理岗的具体情境
- 岗位实际要求

**怎样算通过：**

- 说明将从哪个新维度解释提拔差异。

**这些情况不通过：**

- 反复宣称现实如此，未进入岗位或行为比较。

**迁移到东头：**从工作投入与晋升结果的落差转入岗位职责差异。

### S09｜升职本质与两类职责（核心）

原文起句：我们来看一下啊，提拔一个人，或者说让一个人升职的本质是什么？

原稿位置：完整原稿字符 1976–2263（从0计数，右端不含）；连续覆盖正文 45.3%–52.0%。

**这一环的作用：**把提拔解释为代理部分职责和压力，区分员工解决具体问题与管理者组织他人解决问题。

**如何衔接：**回答提拔困惑，给后面三种行为提供评价尺度。

**讲述方法：**定义后做两类核心价值对照。

**保留／替换条件：**选用本结构时保留角色职责对照，评价范围由目标岗位限定。

**本篇需要的材料：**

- 员工和管理岗位的正式职责
- 委托管理时需承担的压力与决策

**怎样算通过：**

- 用同一业务解释两类职责的区别。

**这些情况不通过：**

- 只说做人重要，未说明管理任务。

**迁移到东头：**区分独立完成AI任务与组织多人、材料和验收的职责。

### S10｜模糊指令与局部技术回应（核心）

原文起句：我们一个一个来看一下，我帮大家谈一下啊，首先第一个这个人他一定是一个好用的人，

原稿位置：完整原稿字符 2263–2496（从0计数，右端不含）；连续覆盖正文 52.0%–57.5%。

**这一环的作用：**以降本增效、客户满意度的指令对照只优化查询速度的局部回应，展示业务需求与技术动作不匹配。

**如何衔接：**把岗位定义落到第一种行为，下一段给出更完整的回应。

**讲述方法：**同题设置与不足回应。

**保留／替换条件：**选用本结构时保留同一个需求和不足回应，否则无法形成有效对照。

**本篇需要的材料：**

- 一条真实业务指令
- 只完成局部任务的回应及缺口

**怎样算通过：**

- 指出技术动作没有覆盖哪项业务需求。

**这些情况不通过：**

- 仅贬低技术能力，未给同题需求。

**迁移到东头：**用同一个内容或AI项目目标对照局部操作与整体目标。

### S11｜跨部门任务翻译（核心）

原文起句：你们去看一看那个准备被提拔的人，他是怎么回答，

原稿位置：完整原稿字符 2496–2707（从0计数，右端不含）；连续覆盖正文 57.5%–62.4%。

**这一环的作用：**示范把模糊业务目标拆为成本检查、客诉整理、问卷和回访等跨部门行动。

**如何衔接：**修复上段局部回应，接下来将过程汇成上级可读结果。

**讲述方法：**同题替代回应加任务分配。

**保留／替换条件：**选用本结构时保留目标→分工任务的翻译；部门名称和具体行动可换。

**本篇需要的材料：**

- 业务目标的检查维度
- 参与角色、任务、责任与完成节点

**怎样算通过：**

- 每项任务对应目标，并明确由谁完成。

**这些情况不通过：**

- 任务清单存在但无法对应原始目标。

**迁移到东头：**把稿件目标拆成材料核对、读者问题、正文写作和验收分工。

### S12｜过程过滤与结果汇报（核心）

原文起句：然后他把大家干的这些活儿收紧起来，

原稿位置：完整原稿字符 2707–3015（从0计数，右端不含）；连续覆盖正文 62.4%–69.6%。

**这一环的作用：**把分散执行汇成成本、问题解决和满意度结果，并用双向过滤器、翻译器总结第一种行为。

**如何衔接：**承接任务分配的输出，下一项从传达结果转到处理问题。

**讲述方法：**过程到结果的翻译及数字化示范。

**保留／替换条件：**选用本结构时保留结果汇报和目标回扣；示例数字不得写成实际成绩。

**本篇需要的材料：**

- 各任务实际产出
- 可验证指标和变化口径
- 仍未完成的事项

**怎样算通过：**

- 汇报逐项回应原始业务目标，指标有依据。

**这些情况不通过：**

- 照搬10%和五个点，或只有忙碌过程没有结果。

**迁移到东头：**汇报AI内容任务完成什么、依据在哪和还缺什么。

### S13｜抛问题与吸收问题对照（核心）

原文起句：第二点就是他们能够主动的去吞掉问题，

原稿位置：完整原稿字符 3015–3269（从0计数，右端不含）；连续覆盖正文 69.6%–75.6%。

**这一环的作用：**列出团队琐事，对照把问题原样抛给上级与先处理并组织方案的两种行为。

**如何衔接：**从第一种翻译行为转到第二种压力吸收行为，下面用故障和冲突说明。

**讲述方法：**问题列表加角色对照与吸收器比喻。

**保留／替换条件：**选用本结构时保留问题处理对照，先明确需要立即升级的事项。

**本篇需要的材料：**

- 实际问题清单
- 本人可决策范围及上报规则

**怎样算通过：**

- 区分可以先处理与须马上汇报的情况。

**这些情况不通过：**

- 把所有问题不上报都称作创造价值。

**迁移到东头：**对AI流程故障先确认范围和证据，再处理或按规则升级。

### S14｜故障处理与事故报告（有条件采用）

原文起句：服务器崩了，人家第一时间不是去找老板，

原稿位置：完整原稿字符 3269–3437（从0计数，右端不含）；连续覆盖正文 75.6%–79.5%。

**这一环的作用：**以故障举例说明组织抢修、安抚、复盘和报告，让汇报包含原因、方案与责任。

**如何衔接：**具体化吸收问题，下一例转向人际冲突。

**讲述方法：**事件时间线与处理完成后的报告结构。

**保留／替换条件：**涉及故障或异常任务时采用；重大风险须按组织规则同步汇报。

**本篇需要的材料：**

- 异常时间线和实际处理记录
- 原因、措施、责任与预防材料

**怎样算通过：**

- 报告含处理状态、依据和未解决风险。

**这些情况不通过：**

- 只宣布解决了，未给原因或恢复检查。

**迁移到东头：**将AI执行失败整理成影响、证据、恢复结果和下一步。

### S15｜冲突调解与可靠性（有条件采用）

原文起句：再比如说李四吵架了，把李四跟那个产品经理吵吵起来了，

原稿位置：完整原稿字符 3437–3656（从0计数，右端不含）；连续覆盖正文 79.5%–84.6%。

**这一环的作用：**以分歧调解补充吸收问题的方法，回收省心和放心的管理价值。

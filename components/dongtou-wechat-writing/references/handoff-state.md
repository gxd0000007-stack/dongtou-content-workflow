# 当前交接、起步与返修

沿一篇记录：来源/底稿与实际读取范围，原作者观点和事实状态，主题/采用范围，读者/理解起点/目的，收益，方向与标题开头状态，正文问题，主文风/主结构和采用功能，逐段依据及例子经历归属，缺口，允许修改范围，真实文件路径/版本。

第二步起另保留同一份作者视角：作者视角方式（对话共创/直接代写）、我的核心观点、为什么这样看、给读者的建议、观点来源与状态。用户原话、用户已确认、授权代拟分清；完整创作授权下的代拟可继续成第一人称试稿，不逐条等待确认。原作者的观点不能无说明变成东头既有看法。只读原文或用户指定客观体裁时按其范围执行。

用户已选、固定、总控代选、暂拟/试做、待选择分别记。总控代选注明完整创作默认策略或明确授权和依据，不冒称人类确认。最新选择优先旧候选，固定文字保留原文。

阶段标本轮执行、沿用已有、待补/待选择、未执行或不在本轮范围。完整读产物内容再判断，不因文件存在宣布完成；现稿检查不能补造前五步。

| 输入 | 起步 |
|---|---|
| 原文/链接/截图/逐字稿 | 1→2→3A→4→5→6→7 |
| 充分详细读取记录/速读卡 | 2；缺卡可据已有记录补卡 |
| 已选方向和依据 | 3A，必要缺口才回1/2 |
| 当前标题开头卡/正文问题 | 4，已有DNA/结构合适沿用 |
| 逐段讲法卡/材料/固定项 | 5→6→7 |
| 第六步修订稿与实际改稿记录 | 7；已有改稿不冒称本轮新执行 |
| 自己的完整稿 | 按请求3B、5补写、6活人感改稿或7只质检 |
| 当前稿与对应质检报告/回执 | 验证一致直接交；新改动回6后进7终检 |
| 只有片段 | 只处理取得且允许部分，不称全文审查 |

原文身份不清先分清参考作者全文和自己的稿。未取得部分不能当已读全文。

| 改动 | 返回 | 需要重接 |
|---|---|---|
| 原意/证据/事实 | 1定点补读 | 2–7依赖该处的内容 |
| 方向/读者/目的 | 2 | 3–7受影响部分 |
| 我的核心观点/作者视角方式 | 2 | 3–7受影响的标题开头、讲法、正文和验收 |
| 标题/开头/承诺 | 3A或B | 4–7受影响部分 |
| 文风/结构/段落功能 | 4 | 5–7受影响部分 |
| 解释/衔接/冗余 | 5或6允许的修订 | 7受影响项＋当前全文终检 |

未变部分保留，固定项超出许可只提出问题；局部范围适用于所有返修入口。相同缺口无新材料/许可无法靠重复流程解决，交当前稿与具体缺口，以未通过状态结束，不能补造验证。六轮回执、当前稿、报告必须同一全文指纹，总控记录只记实际过程。

第五步记录 human-writing 预读、材料与说话位置；第六步独立记录实际输入/输出指纹、已读改稿规则、真实改动、原包全文/可编辑范围结果及保护依据。第七步审当前稿并保存 human_writing 复验记录。历史记录缺新增工序时不冒称做过；已有充分修订稿和改稿记录可沿用，不能为了新编号重跑所有前步。局部续做只处理真实允许范围。

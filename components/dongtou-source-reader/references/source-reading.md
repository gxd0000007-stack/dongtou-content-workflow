# 来源读取

根据实际输入选择工具。下表是路由与能力边界，不是所有链接都已打通的承诺。

## 本轮打开原始材料

每个新阅读任务都以用户本轮指向的原始文章、文件、图片或视频为阅读对象。先实际打开该材料，再逐项读取本轮可取得的内容。此前的总结或分析可协助定位，但不能单独支持“本轮已完整读取”的说法。已有完整正文可直接作为本轮输入，无需为了重复而重新抓取。

读取回执区分本轮实际打开并读过的内容，与沿用的旧校对记录。复用以前核对过的图片、字幕或画面时，先确认与当前来源对应（例如核对文件哈希），并注明沿用旧记录；不能描述为本轮重新目视、播放或转写。原始来源打不开时，使用真实可用的读取入口，并记录入口、读取结果和具体缺口；不能把仅打开报告或摘要说成已打开原始材料。

| 输入 | 处理与读取范围 |
|---|---|
| 粘贴正文、Markdown、TXT、已有逐字稿 | 直接完整读取；保存段落顺序，原有定位沿用。纯文本底稿可附 P01、P02 编号。 |
| 多张文章截图 | 对全部图片登记顺序，逐图读字／OCR并对图校对；正文、图内文字与平台界面分清，跨页连接有依据。完全重复可映射但原图保留；不清字标具体图与区域。 |
| PDF 或其他文件 | 使用当前已提供的文件阅读能力；扫描页需OCR／目视，图表需实际查看。只拿到文字层就报告图片未读。 |
| 微信公众号链接 | 本机可读 `ra-wechat-article-extractor` 时按其规范取得正文；它返回图片URL，不代表已读图中文字。按本篇需要补读图片并检查尾部。 |
| 其他文章链接 | 使用可用的连接器、浏览器或网页阅读能力，取得实际正文并检查截断。摘录、搜索结果、登录页或标题不能替代全文。 |
| 抖音／小红书视频链接 | 本机可读 `ra-transcript-extractor` 时仅按其范围提取口播；它不代表已看画面，转写时间不是制作级字幕时间。随后在本 Skill 中结合实际可读的字幕与关键画面分析。 |
| 其他平台视频、本地视频／音频 | 根据实际可用的媒体、字幕／转写能力取得内容。音频输入以完整口播为范围；视频关键画面需另读。无匹配能力或授权时说明具体缺口，请求必要材料，不偷偷安装工具或启动生产流程。 |

## 提取与理解之间的交接

记录实际拿到什么：

- 来源：用户提供的标题／作者／链接／文件；未提供且无法确认的留空。
- 内容：正文或转写，截图与图表的说明，实际取得的时间范围。
- 定位：原始段落、页码、图片文件与区域、真实时间戳。保留定位体系，便于报告回查。
- 读取状态：完整原文／完整提供的摘录／仅口播转写／部分内容；全文范围未知就说明未知。
- 缺口：未取得部分、无法辨认处、转写疑点、未读图片／画面；不编补。

完整输入依其来源判断：用户给出的摘录可以全部读完，但不能宣称读完原文章；有完整逐字稿可以读完稿件，但不能宣称看完视频画面。多图组是否完整需要检查，不能仅按文件数推断。

## 视频与图文

口播、字幕、画面文字／图表可能相互补充或矛盾，分别定位。若结论依赖未读图表，暂列依据缺口；文字转写足以理解的部分可以先拆解。不要根据转写凭空描述动作、画面、图表数字或发言者身份。

长视频保留章节或时间范围并检查转写头尾。存在多位发言者时使用素材支持的称呼，身份未知可称“发言者A/B”，标明识别依据；不能凭声音臆测身份。

## 获取失败

先复用可访问的已给内容；遇临时错误按所用工具的规则有限重试。权限／登录／付费／不支持的平台需如实报告，不能绕过授权。可继续分析已取得部分并标明范围；没有可分析正文时只说明取得情况和需要补充什么，不生成假拆解。

提取 Skill 只负责取得内容，其限制与输出路径应尊重。调用前读取本机真实 `SKILL.md`；独立模块之间分阶段交接，不复制外部 Skill 文件、凭证或工具实现。缺工具时说明影响，不把依赖已登记说成已执行成功。

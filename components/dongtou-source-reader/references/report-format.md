# 阅读报告格式

完整读取后，用大白话交付。对话默认先给一屏速读卡；用户要完整拆解、项目需要留档或上游需要复用时，再附详细报告。完整底稿、逐图笔记与技术回执单独保存或放在报告后部，不占据对话首屏。

## 对话默认先给速读卡

速读卡先替用户说清四件事：

1. 作者最想表达什么？用一句完整判断或内容主线说明，并标“作者明说”或“根据全文归纳”。
2. 最重要的观点凭什么成立？挑真正支撑主线的观点，每条后面紧跟一条关键依据和一条证据边界；数量服从原文。
3. 理解主旨必须知道哪些事实？只保留少数关键发布信息、数字、步骤或作者经历，并标明它们来自原文、自述还是图片。
4. 有什么条件会改变理解？只提前说影响主旨的限制、矛盾或读取缺口；其余细节留给完整报告。

短文通常控制在约 300–600 个汉字；复杂材料可以更长，但首屏优先保留统领观点、关键依据和会改变结论的条件。不要为卡字数漏掉来源限定，也不要把每个章节都挤进速读卡。原文位置可用短编号。逐图目录、完整读取渠道、链接清单和逐条核验记录留在详细报告或附件。

## 详细报告

完整拆解时使用以下顺序：**一句话主旨 → 核心观点及依据 → 关键事实 → 条件与疑问 → 读取记录**。详细底稿与理解报告分开。

## 1. 一句话主旨

用一个完整判断说明作者最想表达什么，保留“可能、在某条件下”等限定，标明“作者明说”或“根据全文归纳”。标题涉及的话题不能替代作者立场。原文没有统一主张时，说清内容主线；多个并列主张不强行合并。

补一句这份内容讨论的问题或内容类型即可。来源身份与链接简短给出。读取缺口若影响主旨，先注明“部分内容拆解／全文核心观点暂不能确定”；其他缺口在这里简短提示，详细记录放最后。

## 2. 核心观点及依据

先放统领全文的判断与主要支撑判断，按对主线的重要性组织，数量服从原文。不要逐节把产品名称、发布消息、操作步骤都改写成“观点”；一般功能介绍、事件经过放下一层。重要局部评价可另列，注明它与主线的关系。

每条使用短卡或紧凑表格，至少让用户看懂：

- **作者的判断**：用完整白话句表达，区分中心判断、支撑判断、他人引述或反方观点；说明作者明说还是根据上下文归纳。
- **凭什么这样说**：紧接对应数据、经历、案例、引用、类比或推理，附原文位置。没有依据就写清缺口。
- **这项依据能说明多少**：解释材料如何支撑、限制或反驳观点，区分作者自述、原文引用与已独立核验；不足以推出的结论不要扩大。

观点位置和材料位置都保留真实段落、页码、图片区域或时间。短定位放在相关句后，详细回执放最后。不要把一份截图和同源正文当成两份独立证明，也不要用与观点无关的引用凑依据。

## 3. 关键事实

单列理解主张所必需的事实性信息：发生了什么、发布了什么、具体数字、谁在何时说了什么、作者自述做了什么。可以按主题合并，不复制完整发布清单；原文的重要事实、方法步骤或应用前提仍须保留。

每项给来源位置及状态，例如“原文转述发布信息／作者自述／截图所示／已独立核验”。**事实性陈述不是已经证实的事实**。涉及发布时间、产品开放状态、计费、效果或因果的原文说法未核验时，保留这一状态；解释专业词不能补造事实。假设数字、举例合同和宣传承诺不得记成真实事件或实测收益。

## 4. 条件与疑问

优先列影响理解或后续使用的条件：发布与预告、适用范围、比较口径、原文前后矛盾、依据缺失、待外部核验。写清“哪项说法＋什么位置＋为什么还不能确定”，把原文内部疑问与外部待查分开。不重复每条卡片中无关紧要的检查项。

这里梳理原文的边界，暂不替用户选切口、设计个人行动或写新的立场。

## 5. 读取记录

最后给原文的论述路线，以及来源、作者、标题、底稿位置和实际读取范围。逐图清单、转写时段、取得渠道与技术回执有保存需求时放附件或链接；不占据首屏。

区分正文、图片、口播、字幕和画面。完整逐字稿不等于视频全读；抽样画面要注明抽样。未读部分及无法辨认处具体定位，不能编完整率、置信度百分比或以自评分表示用户验收。

## 不同材料如何调整

- **教程**：有作者判断则照常拆观点；没有则以操作目标和方法主线开场，步骤、前提及原作者建议放关键内容层。主张的效果与实际提供的效果依据分开。
- **资讯／故事**：事件主线与作者评论分层，没有评论就不要编观点。信息多不意味着每一节都有分论点。
- **多人访谈**：保留发言者归属、共识和分歧，问题不能自动算提问者的主张。
- **部分材料**：说明已经读到的范围，不能由片段替整篇下结论。

## 保存与交接

报告可在对话中直接交付。需要保存时引用真实底稿或原文件位置；定位编号和纠错依据有说明，未知的作者、日期与标题不补造。整理标题明确标注。

上游能据此分清：原作者的关键判断、对应材料、事实性信息、限制及读取状态。交接仍停在读懂来源，不自动进入 DNA 匹配或写作。
